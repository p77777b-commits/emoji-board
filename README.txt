ARISE PORTAL MVP v0.3 — 통합 검토본

현재 구성
- index.html   : HOME
- emoji.html   : 기존 운영 이모지판 연결
- memo.html    : Memo v0.2 기준본
- todo.html    : Todo v0.3 (하위 펼침/완료 토글 역할 분리)
- toolbox.html : Toolbox 1차안
- guide.html   : Guide / Help / About 1차안

현재 통합 원칙
- HOME: Emoji / Memo / Todo / Toolbox 4개 핵심 입구
- 체크박스: 완료·취소선 전용
- ▸/▾: Todo 하위항목 열기·접기 전용
- Todo 미완료/완료 2영역 유지
- Memo/Todo 데이터: 현재 브라우저 localStorage
- Notion 동기화: 후속 공정
- 이어서 하기 / 통합 최근 / 통합검색: 상태공유 기반 마련 전 보류

검토 순서
1. index.html 실행
2. HOME 4개 입구 확인
3. Memo 진입 및 저장/검색/정렬 확인
4. Todo 진입 → 상위 할일 → ▸ → 하위 할일 → 개별 체크 확인
5. Toolbox / Guide 동선 확인

주의
- 아직 GitHub Pages 공식 배포본으로 확정하지 않음.
- 개인 메모/Todo 데이터 파일을 GitHub 저장소에 직접 올리지 않음.
